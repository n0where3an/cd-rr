Explanation
-----------

m2cdm version 1.5.1e (2012/01/01) (based on DeXT's mode2cdmaker 1.5.1)

This program is based on DeXT's mode2cdmaker version 1.5.1
(http://dext.peque.org/xcd/mode2cdmaker-1.5.1-src.zip), with minor
bug fixes, some improvements and few restrictions concerning command
line interpretation (filenames in command line is not allowed, except
paramfile - we need this amendment for correct processing of Russian
letters in filenames).

Because of historical purposes, :-) we decided to rename original
readme.txt to Mode2CDMaker.txt and leave it untouched, and to describe
the program shortly in separate file called m2cdm.txt (i.e. this file
:-) instead. Howewer, we strongly recommend to read the original
Mode2CDMaker.txt if you want to understand this program well.

Also, we decided to not include dat2file program with the package.

And one more remark: Elic Megabugger and redtigra are my callsigns,
and "-= Elicit Gingers =-" are both me and my beloved wife; so we
suggested to join our nicknames and develop software together. :-)

Usage
-----

m2cdm -paramfile <parameter-file>

m2cdm -h, m2cdm -help    this help

Commands in paramfile (one per line, command parameter in separate line):
-v, -volume  volume name (default: RR_XCD)
-o, -output  output image base name (*.bin, *.toc, *.cue) (default: image)
-f, -file    add Form1 files
-m, -movie   add movie (Form2) files (by default)
-d, -dir     add subdirectory
-e, -ext     set default extension for Form2 files (default: DAT)
-c, -dos     assume OEM/DOS charset for input file names
-x, -extname keep original Form2 file extension
-s, -single  create a single track image
-ccd         output CloneCD image (*.img, *.sub, *.ccd)
-raw         output RAW-96 image (*.img)
-list        use filelist for input Form1 files
-paramfile   use secondary parameter file for input (NOT TESTED YET!)
-isolevel1   force ISO 9660 Level 1 for file names
-isolevel2   force ISO 9660 Level 2 for file names
